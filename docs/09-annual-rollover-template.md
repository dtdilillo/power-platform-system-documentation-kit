# 09 — Annual rollover template

School-year or fiscal-year partitioning is common. The procedure is not "create a folder." It is change control.

## Checklist

- [ ] New year folder exists in the document library
- [ ] File-name prefix updated in any flow that writes files
- [ ] Page text that names the year is updated
- [ ] Public-list view still sorts the way applicants need
- [ ] Closed prior-year packets remain reachable or are moved by a written rule
- [ ] Administrators roster still current
- [ ] Test: one scheduled item publishes into the **new** folder
- [ ] Test: one old link still behaves as the written rule requires

## Unresolved until proven

- Whether flows hard-code the year string
- Whether the page builds packet links from a column or from a path convention
- Who owns the first week of the new year

Write owners and dates in the private annex, not in this public file.
