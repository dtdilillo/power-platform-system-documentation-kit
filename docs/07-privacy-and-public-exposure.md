# 07 — Privacy and public exposure

## Public-safe

- Method text
- Blank templates
- Generic component names (`Posting Requests`, `Current Openings`, `Reference Number`)
- Generic flow purpose sentences that do not match a live flow title character-for-character if that title is unique to one tenant
- Architecture diagrams with role names (requester, reviewer, applicant)

## Never public

- Person names from an administrator list
- Email addresses, phone numbers, shared mailboxes
- Tenant, site, list, or environment URLs
- Production flow JSON
- Production app YAML
- Real posting packets
- Requester or applicant records
- Snapshot inventories that identify how many live items sit in each status
- Exact production folder paths combined with the exact production identifier scheme

## Job-packet rule

A public GitHub URL is the citation. A live MASTER file is not an attachment.

If a reviewer asks for "the actual system doc," offer a walkthrough under agency rules, not a file drop.
