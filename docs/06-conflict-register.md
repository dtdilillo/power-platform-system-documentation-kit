# 06 — Conflict register

When two sources disagree, do not silently choose.

## Entry pattern

1. Source A statement (quote or close paraphrase, with filename)
2. Source B statement
3. Analysis (timing, scope, terminology, incomplete extract, or true contradiction)
4. Disposition (both treated as snapshots; both kept; promoted after new evidence)
5. Evidence that would close it

## Common conflict types in this domain

| Symptom | Do not do | Do |
|---|---|---|
| List totals differ by one | Average them | Keep both; call them snapshots |
| Flow note states an automation more firmly than the list note | Upgrade the weaker source | Label Indicated; demand the definition |
| A list column is blank in an extract but the page shows links | Assume the column is unused | Record rendering as Unresolved |
| App is New-mode only; process text says requesters revise in the app | Invent an edit screen | Process intent Verified; path Unresolved |
| Folder path written two ways in one document | Pick one and hide the other | Record both renderings |

Snapshot counts are never architecture.
